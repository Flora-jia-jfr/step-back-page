When should a research agent step back?

An agent's answer is not good enough yet. It can analyze more, revise its model, collect more of the same data, or run an experiment that tells competing explanations apart. We measure, against ground truth and counterfactual runs, whether it knows what each of these is worth, and where that judgment breaks.

  1. Q1Does it know what each step is worth?Which one helps more, and by how much, relative to the price.
  2. Q2Where does the call break?In the estimate, in the choice, or in carrying the step out.
  3. Q3Is there room for judgment?Or do simple fixed policies already come close? Reported either way.
  4. Q4Can it be repaired?If it ranks well but misjudges size, does value calibration fix the choice?

The decision

Every analysis reaches a point where the answer is still uncertain. The next step falls into one of four cells, or the agent stops.

Same first answer, four different right moves

An analyst asks whether a drug lowers blood pressure, using records from two hospitals, and must predict its effect in an older population. The working model is the same effect for every patient, after adjusting for severity. What should come next depends on what is actually true:

Motivation

We already know research agents get stuck. What we do not know is how they value their next step, and where that judgment fails.

known
  • Research agents keep tuning when they should rethink (ResearchGym; "frame-lock" in AutoResearch), judged from traces afterwards.
  • Decision methods compare candidates by running them. LLM-IDEA runs every candidate experiment from the same data and reports regret; Outgrow a Theory learns when and how to revise a model class.
missing
  • In those methods a fixed criterion or a learned policy makes the choice, and only one kind of remedy is compared.
  • Nobody has scored an LLM agent's own estimates and choices against the realized value of different kinds of remedies from the same state.

Those methods build better decision mechanisms. We ask how existing agents judge the next step: do they know which remedy helps more, by how much, do they act on it, and do they carry it out?

Preliminary results

In one sentence: Claude knows roughly where new data would help, but thinks they help several times less than they do, so it stops too early.

what we ran
  • The task. A black box with six on/off switches. Each press lights a lamp with a hidden probability that depends on the switches. The agent sees records for half of the switch settings and must predict the lamp's probability for the other half. We know the true probabilities, so every answer can be scored exactly.
  • The moments. 24 saved moments, each right after Claude (Sonnet 5.5) gave its first answer: 12 tasks, each in two versions of the task text.
  • At each moment, from the same saved copy: we asked Claude how much 32 more records would lower its error, and what it would do at three data prices (in copies we then threw away). Separately, we actually gave it the 32 records, and let it re-analyze the same data for up to four more rounds, and measured how much the error really changed.

One model, two runs per branch, small sample: read only the direction.

The order is mostly right: sorted by Claude's estimate, the moments where data really helped come first (AUC 0.88). The size is wrong, and Claude acts on its own estimates (71 of 72 decisions), so it stops. That is why we measure ranking and size separately, and why the pilot tests whether calibrating the size fixes the choice.

2 · Re-analyzing the same data is cheap and usually worth it

3 · It saw what it could not test

why the pilot needs a new toy

The switch box hides half of the switch settings. In all 12 tasks Claude pointed out that its records could not tell two explanations apart on that hidden half, but the task gave it no way to collect records there. So "step back and test an assumption" was impossible in this toy. The pilot's toy causal model (§05) is built so that it is possible.

Goal and questions

The goal is to measure, against ground truth and counterfactual runs, how well an agent judges what each next step is worth, and where that judgment breaks.

How one state is measured

from one saved moment
1first analysis window→ save→ 2ask, then discard: which move? what would each gain?
run every branch from the save, to the end of the budget, twice
STOPARDX→ 3record each remedy's realized gain, with its spread→ 4compare with its estimates, its choice and what it actually did

The agent decides when its first window ends, and all policies share the same analysis budget. A and R are prompts, so we record both the branch assigned and what the agent actually did. Three prompt conditions (neutral, generic review, framework review) show whether a prompt fixes a failure at this budget; none names a mechanism. A remedy counts as best in a state only when it clearly beats the next one.

Pilot: a toy causal model

A small model built for this question. It only generates the data; the agent's task is prediction, not causal discovery.

setup

Records from two sites: age A, a baseline score S, treated or not T, outcome Y. Predict the mean outcome with and without treatment in an older target population, as measured by a reference lab.

why causal
  • "More of the same data cannot settle it" holds by theory: unmeasured confounding and a real effect fit observational data equally well.
  • Each way of going wrong needs its own kind of evidence, so the remedies have clearly different values from state to state.
why build our own
  • We need look-alike truths, an exact ideal observer and all four remedies together.
  • BoxingGym has one fixed model per environment and no reanalysis action; ACED-Bench does not run remedies from one state.

Plan and stopping rules

Stage 0 (about 300 analysis windows): 4 truths × 2 data sizes × 3 seeds = 24 states, with branches STOP, A, R, D and the three X options. Stage 1 (at most about 800) runs only if Stage 0 passes: more seeds, second runs, controls, the prompt conditions, a start from another run's saved state, and the value-calibration repair on new seeds.
