When should a research agent
reconsider its approach?

We want to understand whether AI research agents can recognize what is limiting progress, evaluate alternative ways forward, and allocate effort accordingly. Strong execution does not guarantee that the agent is working on the right problem.

Changing direction is not automatically better than persisting. The question is whether the agent can tell which response the evidence supports.

Completed
A small measurement prototype

Compare reported action values with continuations from the same saved state. The pilot provides exploratory signals and exposes measurement problems.

Current research task
Find a concrete decision bottleneck

Ground the question in complete research episodes before expanding the synthetic environment. No general strategic failure has been established.

01The completed task

A simple task with a useful complication

Six binary switches control a lamp. The agent observes noisy on/off outcomes and predicts the lamp’s probability of lighting at configurations it has never observed.

What the agent sees

32 or 128 observations, drawn from the 32 configurations with an even number of switches on. It has a Python tool for analysis.

What we score

Predicted probabilities at the other 32 configurations, with an odd number on. Loss is mean squared error (MSE) against the generating probabilities.

The hidden rule has no effect, one main effect, a two-switch interaction, or both. The agent is not given this list of candidate rules. An MSE of 0.01 corresponds to a root-mean-square probability error of 10 percentage points.

At N = 32, each observed configuration is sampled once. The extra balanced batch samples each of those same configurations once more. It does not reveal any held-out configuration.

Why the split creates an ambiguity

A low-order rule and its complementary high-order rule can agree on every even configuration and disagree on every odd one. More even observations reduce sampling noise but cannot distinguish these rules. Predicting the odd half therefore requires a structural assumption. This matters when interpreting “more analysis” as progress.

03Evidence so far

Some improvements were missed.
The reason is not yet isolated.

The pilot shows that the comparison can be run. Some states improved substantially after additional data, but task assumptions, execution effects, and the allocation mismatch limit what we can infer about judgment.

How to read the reported AUC values

Across all 24 states, data-gain AUC is 0.88 and one-window analysis-gain AUC is 0.50. These use each state’s gain estimate averaged over all three prices, and label a state positive when its realized raw gain is at least 0.002. They compare one action across states, not action ranking within a state or whether buying data beats its price. The interactive scatter instead uses the original response at the selected price.

04Interpretation

What the pilot does—and does not—establish

The defensible result is a feasibility demonstration and a set of measurement lessons. It does not yet establish a general failure of research strategy.

The actions do not quite match

The elicited data estimate concerns the agent’s allocation; the continuation uses balanced observations. A direct difference mixes value judgment with action definition.

Some uncertainty is structural

The even/odd split leaves observationally equivalent rules. Additional records can reduce noise without resolving how to extrapolate to the held-out half.

Execution affects the outcome

Token caps and different handling of long responses can influence improvements. Two continuations per action are too few to establish a precise expected value.

The evidence is a summary snapshot

The saved per-state table supports the numerical checks. Full raw transcripts are unavailable in the local snapshot, so behavior-level verification and reproduction remain incomplete.

What the statistical references assume

Ref-G knows the four generating rule families. Ref-O uses a broader sparse low-order model, but sets higher-order effects to zero and uses numerical approximations. Neither is an assumption-free measure of what this agent should have known or could recover. The figures above use recorded agent outcomes, not a reference observer’s predictions.

Status boundary: the new causal environment, diagnosis-specific actions, and a learned controller have not been implemented or evaluated. The earlier four-category action proposal remains a possible future design, not part of these results.

05The question now

From choosing a step to explaining a bottleneck

Our literature review found close work on next-step selection, failure diagnosis, diagnostic experiments, and counterfactual continuation values. These ingredients alone do not establish novelty. We need a specific recurring mechanism and its consequences.

Can a research agent revise its explanation of a bottleneck—and use that explanation to predict which interventions will help, and where they will fail?

This is an exploratory focus, not an established contribution or a fixed experimental design.

A motivating case: performance versus its cause

The Weight-Space Programming article illustrates how low math performance can reflect a generation-control obstacle. Removing that obstacle is a narrower claim than creating new mathematical ability.

The setup requires weight editing; it does not establish whether an agent would autonomously choose that intervention level. The released Qwen and Gemma logs are candidate case-study material. The article and experiment documentation have been checked; the full trajectories have not yet been audited.

06Next steps

Start with complete research episodes

  1. Reconstruct what was knowable at each decision.

    Recover the evidence, the agent’s explanation, the actions that explanation suggested, and the later results that supported or challenged it.

  2. Include cases where persistence was right.

    Compare successful persistence, useful reconsideration, and unsuccessful changes of direction. A failure seen afterward is not automatically a bad earlier decision.

  3. Decide whether a recurring phenomenon survives scrutiny.

    Distinguish diagnosis from execution and measurement. Retain the synthetic prototype; defer expansion until the target mechanism and fair comparison are clearer.

For discussion

Is revising the explanation of a research bottleneck a useful focus? The recommendation is to test it against concrete cases first, given the overlap with existing diagnosis systems.

Should we expand the synthetic environment now? The recommendation is to wait. The tradeoff is slower benchmark production in exchange for a better-founded question.
